# Minesweeper - C++

Academic Minesweeper game developed in C++ as part of my Systems Engineering studies at Pontificia Universidad Javeriana.

## Description

This project is a console-based Minesweeper game developed in C++. It applies programming fundamentals, algorithms, matrices, functions, structures, and file handling.

The game includes different difficulty levels and several gameplay features designed to make the experience more interactive.

## Features

- Three difficulty levels
- Random mine generation
- Automatic cell revealing
- Mine detection
- Flag system
- Radar system
- Second-life system
- Player statistics
- Ranking system
- Coin system
- Input validation

## Technologies

- C++
- Matrices
- Arrays
- Functions
- Structures
- Loops and conditionals
- Algorithms
- File handling

## Difficulty Levels

The game includes three difficulty levels:

- Easy: 8x8 board with 10 mines
- Medium: 10x10 board with 20 mines
- Hard: 12x12 board with 30 mines

## How to Play

1. Enter your player name.
2. Select the desired difficulty.
3. Choose an action from the game menu.
4. Discover cells by entering their row and column.
5. Avoid mines and use flags to mark suspicious cells.
6. Use the radar when available.
7. Discover all non-mine cells to win the game.

## Project Purpose

This project was developed as an academic programming project to practice problem-solving and apply programming concepts in C++.
